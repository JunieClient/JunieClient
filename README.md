Junie Client v5.41
Welcome to the official repository for Junie Client for Minecraft Bedrock Edition!! This client is packed with custom utility modules, fun cosmetics, performance enhancements, and builder tools designed to upgrade your gameplay experience.

Highlights
Builder & Architect Tools: Selection wands, instant fill/clear options, and custom brushes.
Combat & PvP Modules: Fullbright, Auto-Sprint, macros, and utility HUDs.
And More!!
Tip: use feather to toggle something :0?

How to Install
Go to the Releases section on the right side of this page.

Download the JunieClient_v5.41.mcpack file from the latest release.

Double-click or open the file to automatically import it into Minecraft Bedrock Edition.

Important: Open your world settings, go to the Experiments tab, and toggle Beta APIs on.

Feedback & Suggestions:
Have an idea for a new feature? Feel free to open an **issues** in the Issues tab above or reach out to share your feedback!

Apply the behavior pack and enjoy!!
